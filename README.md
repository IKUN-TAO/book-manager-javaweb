# 📚 图书管理系统

## 项目简介

本项目是一个基于 JavaWeb 技术开发的图书管理系统，主要功能包括用户登录、注册、管理员与学生角色的权限分离、图书信息的增删改查、图书借阅与归还、借阅记录查看、个人中心信息修改等，适合初学者入门的Javaweb小项目。


---

## 技术栈

### 后端

- Java
- JSP
- MySQL

### 前端

- HTML
- CSS
- JavaScript

---

## 系统功能

### 1. 登录与注册

- 用户可登录系统
- 新用户需先注册

### 2. 图书信息展示

- 展示所有图书信息

### 3. 图书信息查询

- 管理员可进行模糊查询，支持修改与删除
- 学生仅可查询，不支持修改与删除

### 4. 图书添加

- 仅管理员可添加图书

### 5. 图书借阅

- 管理员可借阅图书
- 若数据库无此书，提示“数据库中没有此书”并跳转至添加图书页面

### 6. 图书归还

- 仅管理员可归还图书

### 7. 借阅信息展示

- 展示所有图书的借阅信息

### 8. 个人中心

- 显示姓名和密码（只读）
- 仅邮箱可修改

本项目实现了图书管理系统的基本功能，涵盖用户权限管理、图书信息管理、借阅流程管理等模块。通过本项目的开发，巩固了 JavaWeb、HTML、CSS、JavaScript 等技术的实际应用能力，提升了代码逻辑与系统设计能力。

## 使用说明

1. 导入项目到 IDE（如 IntelliJ IDEA 或 Eclipse）
2. 配置 Tomcat 服务器
3. 导入数据库 SQL 文件
4. 修改数据库连接配置
5. 运行项目，访问 `http://localhost:8080/`
